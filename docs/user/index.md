# 用户端快速开始

欢迎使用 AIGoCode！只需 5 分钟，你就能在自己喜欢的 AI 工具中接入 GPT-4、Claude 等主流模型。

## 📦 配置信息（直接复制）

```
接口地址：https://api.aigocode.app
推荐模型：gpt-4o / claude-3-5-sonnet / gemini-pro
```

## 🚀 三步开始

### 1. 获取 API Key

1. 访问 [AIGoCode 用户端](https://www.aigocode.app/)
2. 注册并登录
3. 进入【个人中心】→【API 密钥】
4. 点击【创建密钥】，复制保存

:::tip 💡 提示
API Key 只显示一次，请妥善保管。如果丢失，可以重新创建。
:::

### 2. 选择你的工具

我们支持主流 AI 客户端：

- [Cherry Studio](/user/clients/cherry-studio) - 推荐新手，界面友好
- [ChatBox](/user/clients/chatbox) - 跨平台，简洁易用
- [Cursor](/user/clients/cursor) - AI 编程神器
- [沉浸式翻译](/user/clients/immersive-translate) - 网页翻译
- [OpenClaw](/user/clients/openclaw) - 命令行工具

点击上面的链接，查看对应工具的详细配置步骤（含截图）。

### 3. 开始使用

配置完成后，在客户端中发送一条消息测试：

```
你好，请介绍一下你自己
```

如果收到回复，说明配置成功了！🎉

## ❓ 遇到问题？

- **401 错误** → API Key 填错了，重新复制粘贴
- **连接超时** → 检查网络，或者在配置中关闭代理
- **模型不存在** → 检查模型名是否正确，参考[支持的模型](/user/models)

更多问题请查看 [常见问题](/user/faq)
