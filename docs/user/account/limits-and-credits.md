# 额度与限制

套餐额度、恢复周期、周限额和并发限制。

## 并发限制

| 套餐 | 并发限制 |
|------|---------|
| 灵活用户 | 5 |
| 标准版 | 5 |
| 专业版 | 5 |
| 大师版 | 6 |
| 企业版 | 100 起 |

## 额度规则

- 额度会根据模型调用消耗。
- 不同模型的输入、输出、缓存读写成本不同。
- 部分套餐有容量、恢复周期和周限额。
- 当余额或周限额不足时，请求可能返回 403。

## 常见问题

| 问题 | 说明 |
|------|------|
| 为什么余额扣得比预期多？ | 长上下文、大输出、缓存写入、工具重复请求都会增加消耗。 |
| 为什么订阅额度没恢复？ | 可能仍在恢复周期内，或已经触发周限额。 |
| 为什么出现 429？ | 通常是并发请求过多，先降低工具并发或稍后重试。 |
| 灵活用户能用哪些模型？ | 灵活用户按正价消耗额度，通常不因套餐折扣限制模型。套餐用户因享受折扣，部分高成本模型可能会按套餐规则限制。 |

如需查看具体请求记录，请前往主站[用量统计](https://aigocode.app/dashboard/stats)。
