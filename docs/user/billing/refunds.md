# 退款说明

AIGoCode 退款、订阅取消和支持入口。

退款是否支持、可退金额、处理周期和地区限制，可能受支付渠道、套餐状态和实际使用情况影响。正式规则以主站[退款政策](https://aigocode.app/refund-policy)为准。

## 申请退款需要提供

- 注册邮箱或账号信息
- 订单号或支付记录
- 遇到的问题描述
- 是否已经产生模型调用消耗

## 常见情况处理

| 情况 | 建议 |
|------|------|
| 买错套餐 | 尽快联系支持，说明目标套餐 |
| 工具无法连接 | 先按[错误码](/user/errors)排查，仍无法解决再联系 |
| 订阅不想继续 | 在控制台或支付入口取消续订 |
| 消耗记录有疑问 | 提供时间、模型、工具和请求现象，方便核查 |

联系入口：[售后支持](https://aigocode.app/contact-support)。
