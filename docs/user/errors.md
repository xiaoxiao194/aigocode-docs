# 错误码说明

AIGoCode 常见 API 错误码、原因和处理方式。

遇到请求失败时，先看 HTTP 状态码，再看响应体里的错误信息。

## 401 Unauthorized

| 项目 | 说明 |
|------|------|
| 错误现象 | 返回 401 Unauthorized、工具提示 API Key 无效 |
| 可能原因 | Key 复制不完整、Key 已删除、请求头没有带 Bearer、工具填错字段 |
| 解决方法 | 重新复制 Key，检查 `Authorization: Bearer sk-...`，必要时重新创建 Key |
| 是否扣费 | 通常不扣费 |
| 是否联系客服 | 重建 Key 后仍失败再联系 |

## 403 Forbidden / 额度不足

| 项目 | 说明 |
|------|------|
| 错误现象 | 返回 403 或余额、额度、订阅不足相关提示 |
| 可能原因 | 当前余额不足、套餐额度未恢复、周限额已触发 |
| 解决方法 | 查看控制台余额和用量记录，等待恢复或升级套餐 |
| 是否扣费 | 请求未成功生成时通常不继续扣费 |
| 是否联系客服 | 余额显示异常时联系 |

## 413 Payload Too Large

| 项目 | 说明 |
|------|------|
| 错误现象 | 返回 413 Payload Too Large |
| 可能原因 | 输入内容、文件、上下文或历史消息过大 |
| 解决方法 | 缩短上下文、删除无关文件、降低一次请求的输入规模 |
| 是否扣费 | 通常不扣费 |
| 是否联系客服 | 一般不需要 |

## 429 Too Many Requests

| 项目 | 说明 |
|------|------|
| 错误现象 | 返回 429 Too Many Requests，CLI 突然连不上或连续失败 |
| 可能原因 | 同时发起的请求过多、工具自动并发、短时间重试过快 |
| 解决方法 | 降低并发，关闭多余客户端，等待片刻后重试 |
| 是否扣费 | 未完成的失败请求通常不扣费 |
| 是否联系客服 | 长时间持续出现再联系 |

## 5xx 服务端错误

| 项目 | 说明 |
|------|------|
| 错误现象 | 返回 500、502、503、504 |
| 可能原因 | 上游模型波动、网络问题、服务临时异常 |
| 解决方法 | 稍后重试，或切换模型 |
| 是否扣费 | 以最终生成和用量记录为准 |
| 是否联系客服 | 持续影响使用时联系 |

## 排查清单

遇到问题时，按顺序检查：

- API Key 是否完整且未泄露
- Base URL 是否按协议填写（见 [Base URL 说明](/user/getting-started/base-url)）
- 模型 ID 是否正确
- 当前套餐是否有足够额度
- 是否同时开了多个工具或会话
