# Cherry Studio 配置指南

Cherry Studio 是一款界面友好、功能强大的 AI 客户端，支持多模型切换、对话管理等功能。

## 前置要求

- 已注册 AIGoCode 账号
- 已获取 API Key（[获取方式](/user/#_1-获取-api-key)）
- 已安装 Cherry Studio（[官网下载](https://cherry-ai.com/)）

## 📦 配置信息（直接复制）

在开始前，准备好以下信息：

```
接口地址：https://api.aigocode.app/v1
API Key：你的密钥（在个人中心获取）
推荐模型：gpt-4o
```

## 配置步骤

### 1. 打开设置

启动 Cherry Studio，点击左下角的 **设置图标** ⚙️

### 2. 添加服务提供商

1. 在设置页面，点击左侧 **「模型服务商」**
2. 点击右上角 **「+ 添加」** 按钮
3. 选择 **「OpenAI」** 类型（因为 AIGoCode 兼容 OpenAI 格式）

### 3. 填写配置

在弹出的配置窗口中，按照以下内容填写：

| 配置项 | 填写内容 |
|--------|----------|
| **名称** | `AIGoCode`（可以自定义） |
| **Base URL** | `https://api.aigocode.app/v1` |
| **API Key** | 你的 API Key（粘贴从个人中心复制的密钥） |

:::tip 💡 提示
- Base URL 末尾不要加 `/chat/completions`
- API Key 前后不要有空格
- 可以勾选「测试连接」来验证配置是否正确
:::

### 4. 选择模型

配置完成后，点击 **「保存」**，然后：

1. 回到主界面
2. 点击顶部的 **模型选择器**
3. 在下拉列表中，找到 **AIGoCode** 分组
4. 选择 `gpt-4o` 或其他你想用的模型

## 验证是否成功

在对话框中发送一条测试消息：

```
你好，请介绍一下你自己
```

如果收到正常回复，说明配置成功了！🎉

## 💡 使用技巧

### 多模型切换

配置完成后，你可以随时在顶部切换不同的模型：

- **gpt-4o** - 综合性能好，适合日常使用
- **gpt-4o-mini** - 速度快、便宜，适合简单任务
- **claude-3-5-sonnet** - 擅长复杂推理和长文本

### 对话管理

Cherry Studio 支持：
- 创建多个对话
- 重命名对话
- 导出对话记录
- 搜索历史对话

### 自定义系统提示词

在每个对话中，可以点击顶部的「系统提示词」按钮，设置角色和行为，例如：

```
你是一个专业的 Python 编程助手，擅长解释代码和解决问题。
```

## 常见问题

### 401 Unauthorized 错误

**原因：** API Key 填错了

**解决：**
1. 回到【个人中心】→【API 密钥】
2. 重新复制密钥
3. 在 Cherry Studio 设置中更新 API Key
4. 注意不要有多余的空格

### 连接超时

**原因：** 网络问题或代理设置不当

**解决：**
1. 检查网络连接
2. 如果使用了代理，在 Cherry Studio 设置中关闭代理
3. 或者在代理软件中添加例外规则

### 模型不存在

**原因：** 模型名称填错了

**解决：**
1. 检查拼写是否正确
2. 参考 [支持的模型列表](/user/models)
3. 使用复制粘贴，避免手动输入

### 找不到 AIGoCode 的模型

**原因：** 配置可能没有保存

**解决：**
1. 重新进入设置
2. 检查 AIGoCode 服务商是否存在
3. 如果不存在，重新添加
4. 保存后重启 Cherry Studio
