# 计费规则

AIGoCode 用户端采用按实际使用量计费的方式，灵活透明。

## 计费方式

### 按 Token 计费

- **无月费**：不需要每月固定付费
- **按需使用**：只为实际的 API 调用付费
- **灵活充值**：随用随充，无最低消费

### 什么是 Token？

Token 是计算使用量的单位。简单理解：

- **1 个 Token** ≈ 0.75 个英文单词
- **1 个 Token** ≈ 1.5 个中文字符

**示例：**
- "你好世界" ≈ 6 个 Token
- "Hello, how are you?" ≈ 5 个 Token

## 费用示例

### 示例 1：简单对话

**场景**：日常闲聊  
**输入**："介绍一下你自己"（约 10 tokens）  
**输出**：一段 100 字的介绍（约 150 tokens）

使用 `gpt-4o`:
```
输入费用：10 × ¥0.015/1K = ¥0.00015
输出费用：150 × ¥0.060/1K = ¥0.009
总计：¥0.00915
```

### 示例 2：写作任务

**场景**：写一篇 500 字的文章  
**输入**："写一篇关于AI的文章，500字"（约 20 tokens）  
**输出**：一篇 500 字的文章（约 750 tokens）

使用 `gpt-4o`:
```
输入费用：20 × ¥0.015/1K = ¥0.0003
输出费用：750 × ¥0.060/1K = ¥0.045
总计：¥0.0453
```

### 示例 3：代码生成

**场景**：生成一个 Python 函数  
**输入**："写一个排序函数"（约 15 tokens）  
**输出**：包含注释的代码（约 200 tokens）

使用 `gpt-4o`:
```
输入费用：15 × ¥0.015/1K = ¥0.000225
输出费用：200 × ¥0.060/1K = ¥0.012
总计：¥0.012225
```

## 每日使用成本参考

### 轻度使用（20 次对话/天）
- 使用 `gpt-4o-mini`
- 每次平均 100 tokens 输出
- **约 ¥0.024/天**，**约 ¥0.72/月**

### 中度使用（50 次对话/天）
- 使用 `gpt-4o`
- 每次平均 200 tokens 输出
- **约 ¥0.60/天**，**约 ¥18/月**

### 重度使用（100 次对话/天）
- 混合使用 `gpt-4o` 和 `claude-3-5-sonnet`
- 每次平均 300 tokens 输出
- **约 ¥1.8/天**，**约 ¥54/月**

## 如何控制费用

### 1. 选择合适的模型

- **日常对话**：用 `gpt-4o-mini`（便宜 5 倍）
- **复杂任务**：才用 `gpt-4o` 或 `claude-3-5-sonnet`

### 2. 限制输出长度

在客户端设置中调整 `max_tokens`:
- 简单问答：200-500
- 文章写作：1000-2000
- 代码生成：500-1000

### 3. 精简提问

- 避免重复描述
- 直接说重点
- 不要一次性要求太多

### 4. 设置预算告警

在【个人中心】设置：
- 每日消费上限
- 余额告警
- 超出自动通知

## 常见问题

### 会自动扣费吗？

不会。只在你实际使用时扣费，余额不足时停止服务。

### 充值有有效期吗？

没有有效期，充值后永久有效。

### 可以开发票吗？

个人用户端暂不支持发票。如需发票请使用[企业端](/enterprise/)。

### 如何退款？

充值后不支持退款。建议先充值少量金额试用。
