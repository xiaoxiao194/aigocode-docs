**推荐场景:** 日常使用、通用任务

## 如何选择?

### 日常使用
推荐 **gpt-4o** - 综合性能好,价格适中

### 省钱首选
推荐 **gpt-4o-mini** - 便宜快速,日常够用

### 高质量要求
推荐 **claude-3-5-sonnet** - 最强推理和代码能力

### 快速响应
推荐 **claude-3-haiku** - 速度最快

## 使用说明

### 在客户端中切换模型

大部分客户端支持在对话时随时切换模型:

1. 点击顶部的模型选择器
2. 从列表中选择想用的模型
3. 继续对话即可

### 模型名称

配置时请使用上面列出的**模型名称**,例如:
```
gpt-4o
claude-3-5-sonnet
gemini-pro
```

注意大小写和连字符。

## 价格说明

- 价格按 **Token** 计费
- 1 Token ≈ 0.75 个英文单词 ≈ 1.5 个中文字符
- 输入和输出分别计费
- 实时价格以个人中心显示为准

**费用示例:**

一次普通对话(100 字输入,200 字输出):
```
使用 gpt-4o:
输入: ~150 tokens × ¥0.015/1K = ¥0.002
输出: ~300 tokens × ¥0.060/1K = ¥0.018
总计: ¥0.020
```

## 常见问题

### 如何知道用了多少 Token?

在【个人中心】→【使用统计】可以查看详细的使用记录。

### 可以限制每次的费用吗?

可以在客户端设置中调整 `max_tokens` 参数,限制每次回复的最大长度。

### 不同模型可以共用对话历史吗?

可以。你可以在同一个对话中切换模型,之前的对话历史会保留。
