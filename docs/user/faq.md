# 常见问题

## 账号与充值

### 如何注册账号？

访问 [AIGoCode 用户端](https://www.aigocode.app/)，点击【注册】按钮，填写邮箱和密码即可。

### 如何充值？

1. 登录后进入【个人中心】
2. 点击【充值】
3. 选择充值金额
4. 使用支付宝或微信支付完成

### 充值后多久到账？

通常即时到账。如果超过 5 分钟未到账，请联系客服。

### 余额不足会怎样?

当余额不足时，API 调用会失败并返回错误。建议设置余额告警,在余额低于一定金额时收到通知。

## API Key

### 如何创建 API Key？

1. 登录【个人中心】
2. 进入【API 密钥】页面
3. 点击【创建密钥】
4. 设置名称（可选）
5. 复制并保存密钥（只显示一次）

### API Key 丢了怎么办？

API Key 只在创建时显示一次。如果丢失，需要：
1. 在【个人中心】→【API 密钥】中删除旧密钥
2. 重新创建一个新密钥
3. 在客户端中更新为新密钥

### 可以创建多个 API Key 吗？

可以。你可以为不同的设备或工具创建独立的密钥，方便管理。

### 如何保护 API Key？

- 不要分享给别人
- 不要提交到公开的代码仓库
- 如果怀疑泄露，立即删除并重新创建
- 定期更换密钥

## 配置问题

### 401 Unauthorized 错误

**原因：** API Key 填写错误或已失效

**解决方法：**
1. 检查 API Key 是否正确（注意不要有多余空格）
2. 确认密钥是否已在个人中心删除
3. 重新复制粘贴密钥
4. 如果还是不行，创建新密钥重新配置

### 连接超时

**原因：** 网络问题或代理设置

**解决方法：**
1. 检查网络连接是否正常
2. 如果使用了代理，在客户端设置中关闭代理
3. 或者在代理软件中添加 `api.aigocode.app` 为直连规则
4. 尝试切换网络环境（WiFi/流量）

### 模型不存在

**原因：** 模型名称填写错误

**解决方法：**
1. 检查模型名拼写是否正确
2. 参考[支持的模型列表](/user/models)
3. 常用模型名：`gpt-4o`, `gpt-4o-mini`, `claude-3-5-sonnet`
4. 使用复制粘贴，避免手动输入

### Base URL 填什么？

大部分工具填写：
```
https://api.aigocode.app/v1
```

有些工具可能需要完整路径：
```
https://api.aigocode.app/v1/chat/completions
```

具体请参考对应工具的配置指南。

### 找不到 AIGoCode 的模型

**可能原因：**
- 配置没有保存
- 客户端需要重启
- Base URL 填写错误

**解决方法：**
1. 检查配置是否保存成功
2. 重启客户端软件
3. 重新添加服务提供商
4. 参考对应工具的配置指南中的截图

## 使用问题

### 回复速度慢

**可能原因：**
- 当前负载较高
- 选择的模型较慢
- 网络延迟

**优化方法：**
1. 尝试使用 `gpt-4o-mini`（速度更快）
2. 减少 `max_tokens` 参数
3. 检查网络连接
4. 避开使用高峰期

### 回复中断或不完整

**可能原因：**
- 达到 `max_tokens` 限制
- 网络中断
- 触发了内容过滤

**解决方法：**
1. 增加 `max_tokens` 设置
2. 检查网络稳定性
3. 调整提示词内容
4. 尝试分段提问

### 如何查看使用量？

1. 登录【个人中心】
2. 进入【使用统计】
3. 可以查看：
   - 每日调用次数
   - Token 使用量
   - 费用明细
   - 按模型分类的统计

### 如何控制费用？

1. **选择合适的模型**
   - 日常任务用 `gpt-4o-mini`
   - 复杂任务才用 `gpt-4o` 或 `claude-3-5-sonnet`

2. **限制输出长度**
   - 在客户端设置中调整 `max_tokens`
   - 通常 500-1000 就够用

3. **设置预算告警**
   - 在【个人中心】设置每日/每月预算
   - 超出后会收到通知

4. **定期检查**
   - 查看【使用统计】
   - 分析哪些场景用得多
   - 优化使用习惯

## 功能问题

### 支持联网搜索吗？

部分模型支持（如 `gpt-4o-mini` 等）。在提示词中明确要求搜索即可。

### 支持图片识别吗？

支持。使用支持视觉功能的模型（如 `gpt-4o`），在客户端中上传图片即可。

### 支持语音输入/输出吗？

这取决于你使用的客户端软件。AIGoCode 本身提供的是文本 API，语音功能由客户端实现。

### 支持文件上传吗？

支持。在支持文件上传的客户端中，可以上传文档、代码等文件让 AI 分析。

## 安全问题

### 我的对话会被保存吗？

AIGoCode 不会永久保存你的对话内容。只在必要时临时存储用于服务质量监控，定期自动删除。

### API Key 被盗用怎么办？

1. 立即在【个人中心】删除该密钥
2. 创建新密钥
3. 检查【使用统计】中是否有异常调用
4. 联系客服说明情况

### 如何保护账号安全？

- 使用强密码
- 不要分享 API Key
- 定期更换密钥
- 启用两步验证（如果有）

### 和直接用 OpenAI 有什么区别？

**优势：**
- 支持多个模型（不只 OpenAI）
- 国内访问更稳定
- 灵活的付费方式
- 中文客服支持

**区别：**
- 价格可能略有不同
- 功能基本一致
- 可能有请求频率限制

### 企业用户和个人用户有什么区别？

**个人用户（你现在所在）：**
- 在 AI 客户端中使用
- 按需充值
- 适合个人使用

**企业用户：**
- 通过 API 集成到应用中
- 批量调用
- 提供发票
- 详见[企业端文档](/enterprise/)
